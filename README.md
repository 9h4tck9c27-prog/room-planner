# Room planner

A single-page 3D room planner for placing furniture by exact dimensions (inches). Drag pieces, rotate, flip sectional chaise side, and edit width/depth/height.

- Static site: `index.html` + `three.min.js` (three.js r128, vendored). No build step.
- Layout is saved in the browser (localStorage).
- Netlify: connect the repo, leave build command empty, publish directory `.`
